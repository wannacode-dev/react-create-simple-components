# React: создание компонентов

Набор React-заданий, где каждое задание и его решение запускаются отдельной npm-командой.

## Установка

```bash
git clone https://github.com/wannacode-dev/react-create-simple-components.git
cd react-create-simple-components
npm install
```

## Как запускать задания

Запуск **задачи**

```bash
npm run task
```

Запуск **решения**

```bash
npm run solution
```

Дальше просто открывай адрес, который выведет Vite в терминале (обычно `http://localhost:5173`).

## Как проходить курс

Курс разделён на упражнения. Каждое упражнение содержит файлы `*.проблема.jsx` и `*.решение.jsx`.

### Чтобы пройти упражнение:

1. **Запусти задание:**
   ```bash
   npm run task:01
   ```

2. **Попробуй решить самостоятельно:**
   - Открой файл `src/01-первое-приветствие.проблема.jsx`
   - Изучи код и найди проблему
   - Попробуй исправить, используя [документацию React](https://react.dev/)
   - Проверь результат в браузере (`http://localhost:5173`)

3. **Проверь решение:**
   
   Если справился или застрял — запусти готовое решение:
   ```bash
   npm run solution-01
   ```
   
   Сравни своё решение с предложенным. Возможно, твоё решение лучше!


## Советы по обучению

Этот курс предполагает, что если вы не понимайте что происходит, то вам нужно исследовать задание:

- **Не спеши смотреть решение** — попробуй найти ответ самостоятельно
- **Используй документацию** — [React Docs](https://react.dev/) твой лучший друг
- **Экспериментируй** — меняй код и смотри, что происходит
- **Сравнивай решения** — твой подход может быть интереснее готового!
